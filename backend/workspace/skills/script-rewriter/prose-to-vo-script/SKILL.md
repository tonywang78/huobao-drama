# 散文 → 旁白视频剧本

本 skill 激活时，**以本规范为准**，覆盖底座「小说→对白/动作剧本」的格式与说话密度规则。

建议：勾选本 skill 时关闭底座 `script-rewriter`，避免对白规范冲突。

## 改写目标

把散文（景点介绍、游记、随笔、心情日记等）改写成可拍、可配音的**旁白视频剧本**：

1. **无角色对白**：不出现 `角色名：（状态）台词`；不做人物对戏
2. **纯旁白**：旁白供用户自行录制；语句适合口播，节奏可跟画面
3. **画面可拍**：每场有独立、可视化的画面描写，不写景别/运镜等镜头语言
4. **保留原意与气质**：不篡改事实与核心情绪；可重组段落、补全可视细节以便成片

## 输出格式

```
## S01 | 外景 · 西湖断桥 | 清晨

画面：薄雾贴着湖面流动，断桥石栏在雾中若隐若现，远处柳丝几乎不动。

旁白：清晨的西湖，像一张还未完全展开的宣纸。断桥就站在纸的折痕上，等第一笔淡墨落下。
```

### 格式规则

- `## S编号 | 内景/外景 · 地点 | 时间段` — 场景头；编号连续 S01、S02…
- `画面：` — 可见、可拍的环境与动态（光影、天气、物件、人物若出现则只写可见动作/神态，不写内心独白对白）
- `旁白：` — 该场口播文案；一句或短短几句，朗读约 8–20 秒为宜
- **禁止**：角色对白行、画外对谈、采访问答体、镜头术语（特写/推拉/航拍等）

### 内容量参考

- 一场 = 一段旁白 + 一组连贯画面，约 15–40 秒成片节奏
- 旁白总时长随原文；不要为「显得完整」大幅注水，也不要删到只剩标题句
- 画面描写服务旁白与成片，不是扩写散文本身

## 改写原则

1. **先拆场再写旁白**：按空间、时间或情绪转折切场，避免一场塞完整篇文章
2. **旁白口语化**：保留原文意象与金句；把书面长句收成适合朗读的短句；少用生僻书面结构
3. **画面与旁白对齐**：旁白说到的意象，画面里要有对应可见元素；旁白未提的，画面可不强行加戏
4. **人物处理**：原文若有「我」或他人，画面可写可见行为；旁白可用第一人称或第三人称，与原文视角一致，但不要写成角色互相对话
5. **时间段要具体**：清晨、黄昏、雨夜等；避免笼统「白天」（除非原文信息不足且无法合理推断）

## 改写步骤

1. 调用 `read_episode_script` 读取原文（散文）
2. 标出：主题、时空线索、可拍意象、必须保留的金句/信息点
3. 自行按本格式改写完整剧本（**不要**按 `rewrite_to_screenplay` 返回的对白剧格式执行；若调用该工具，只取 `source_content`，改写规范以本 skill 为准）
4. 自检：无对白行；每场皆有「画面：」与「旁白：」；场景编号连续；旁白可朗读
5. 调用 `save_script` 保存最终结果

## 自检清单

- [ ] 全文无 `角色名：（…）台词` 或任何对戏对白
- [ ] 每场均含场景头、`画面：`、`旁白：`
- [ ] 旁白适合用户口播录音，无明显拗口长句堆砌
- [ ] 画面可拍，无镜头语言
- [ ] 事实与原文核心情绪未跑偏

## 例外

用户本轮明确要求「加上人物对白 / 改成对白剧」时，以用户要求为准。
