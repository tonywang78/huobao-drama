# 剧本改写指南

## 改写原则

1. **保留核心情节**：不改变主线故事和角色关系
2. **增强画面感**：将叙述性文字转化为可视化的场景描写
3. **保留原作说话密度**：先判断原文对白比例；原文几乎无人说话则只写场景头和可见动作，禁止编台词；原文已有对白则只格式化已有台词，不新增、不扩写成聊天
4. **节奏把控**：每场戏控制在 30-60 秒，适合短视频
5. **不写镜头语言**：不涉及景别、角度、运镜，这些属于分镜拆解步骤

## 原作说话形态（硬规则）

改写是格式化，不是改编成对白剧。

- **先判形态**：通读原文，估计对白 vs 叙述的比例
- **无人说话 / 纯描述**：输出只有场景头 + 动作描写自然段。不要出现 `角色名：（状态）台词` 行，不要用画外音对戏来补「剧本感」
- **已有对白**：把原文里已经说出口的台词收成对白格式，说话人和内容与原文对应。不额外加寒暄、问答、解释性对白
- **心理 / 旁白**：转化为可见的表情、动作、神态。不要把未说出口的心思编成角色对白或两人交谈
- **禁止**：为「更像剧本」而发明对话；把动作暗示（皱眉、对视、伸手）写成台词；把一人叙述扩成多人对戏
- **例外**：用户本轮明确要求「改成对话 / 加强对白」时，以用户要求为准

## 格式化剧本格式

原文已有对白时：

```
## S01 | 内景 · 咖啡厅 | 黄昏

黄昏的光线透过落地窗洒进咖啡厅，吧台上咖啡杯热气升腾。

小明独自坐在角落卡座，低头看手机，神情有些焦虑。

门铃响起，小红推门而入。她看到小明，微笑着走过去。

小红：（微笑）等很久了吗？
小明：（抬头）还好，刚到。
```

原文无人说话、纯描述时（不要补对白）：

```
## S01 | 外景 · 山间公路 | 黎明

薄雾贴着柏油路面流动，远处山脊刚被第一缕冷光切开。

一辆黑色轿车停在路肩。司机坐在车里，双手握着方向盘，盯着后视镜，没有说话。

一只乌鸦落在护栏上，又扑棱飞走。司机推开车门，走向路缘的护栏，低头看向山谷。
```

### 格式规则

- `## S编号 | 内景/外景 · 地点 | 时间段` — 场景头
- 动作描写自然段 — 不包含任何镜头语言
- `角色名：（状态/表情）台词内容` — **仅当原文已有台词时**使用的对白格式

### 内容量参考

格式化剧本相比原始内容增加约 20-30%，主要增量是场景头标记和动作可视化，不是扩写，更不是加对白。

## 改写步骤

1. 先调用 `read_episode_script` 读取原始内容
2. 分析内容结构（对白、叙述、心理描写的比例），判定本集是「叙述为主」还是「对白为主」
3. 调用 `rewrite_to_screenplay` 执行改写
4. 检查改写结果：符合格式化剧本格式；原文无对白则结果不得出现对白行；原文有对白则台词不增不改说话人
5. 调用 `save_script` 保存最终结果

## 注意事项

- 长段叙述拆分为多个短场景
- 确保每个场景有明确的情绪转折点
- 保持角色语言风格一致性（仅针对原文已有台词）
- 场景编号连续递增（S01, S02, S03...）
- 时间段要具体（黄昏、深夜、清晨），不要笼统写"白天"
