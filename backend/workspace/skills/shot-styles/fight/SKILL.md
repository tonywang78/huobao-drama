# 镜头风格：打斗（shot_style=fight）

用于对打、追逐互殴、兵器交锋等段落。只改镜头语法与节奏，不改项目美术风格。

## 拆镜规则

- **子镜头密度**：同一段落优先 **1–2 个**【镜头N】；一条攻防因果链（出招→接触→受力→失衡）尽量同一镜跟完。禁止默认拆成 3–4 个互不连续的短镜
- **切镜**：默认 **不切**（一镜到底跟拍）。仅在「命中瞬间冲击特写」或「倒地/重创结果定格」允许 **至多 1 次** 短切，且前后动作因果必须可读
- **时长**：爆点打斗段 12–15 秒；子镜头偏长（约 **6–12 秒** 一镜），避免 2–3 秒碎切
- **description**：写清攻防双方、连续肢体轨迹、接触点、失衡/落地等可见后果；禁止「打得很激烈」这类空话；禁止把同一连招拆成多个独立【镜头N】
- **movement / shot_type**：中近景跟镜、短促甩镜、推近；用机位运动串连招。少用长时固定全景
- **atmosphere**：尘土、汗光、兵器擦火、撞击声等可感知细节

## video_prompt 规则

在底座 3 秒分段之上追加（覆盖底座「段间硬切」习惯）：

- 仍按 3 秒一行、时间轴连续；但段与段默认用「镜头继续 / 跟拍接上 / 动作不停」衔接，**禁止**每段「切到/切回」
- 只有命中插入特写那一行才写「切到特写…」；下一行立刻「切回跟拍继续…」并衔接上一动作结果
- 每段写清同一空间内的连续动作推进：上一秒的肢体状态必须接到下一秒，不要每 3 秒换一个无关主动作
- 对白尽量少；无对白时写短促动作音（拳风、兵器交击）
