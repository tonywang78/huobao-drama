# 镜头风格：打斗（shot_style=fight）

用于对打、追逐互殴、兵器交锋等段落。只改镜头语法与节奏，不改项目美术风格。

## 拆镜规则

- **子镜头密度**：同一段落优先 3-4 个【镜头N】；每个子镜头聚焦一个可见动作单元（出招 / 闪避 / 命中 / 反应）
- **切镜**：鼓励硬切换景别与对象；拳脚命中前后各给一拍反应或冲击特写
- **时长**：爆点打斗段 12-15 秒；子镜头可偏短（约 2-4 秒），避免拖沓对话式中景
- **description**：写清攻防双方、肢体轨迹、接触点、失衡/落地等可见后果；禁止「打得很激烈」这类空话
- **movement / shot_type**：多用跟镜、甩切感的硬切、特写；少用长时固定全景
- **atmosphere**：尘土、汗光、兵器擦火、撞击声等可感知细节

## video_prompt 规则

在底座 3 秒分段之上追加：

- 段与段之间用「切到/切回」明确硬切；景别在近景、特写、中景间快速切换
- 每段一个主动作（挥拳、格挡、踉跄、砸地）；命中段写清接触点与受力反馈
- 允许同一 3 秒段内写「短促连击 + 立刻切到反应」，但不要跨场景
- 对白尽量少；无对白时写短促动作音（拳风、兵器交击）
