# 镜头风格：纪录片（shot_style=documentary）

用于纪实感、采访旁观、流程跟拍、真实空间观察等段落。只改镜头语法与节奏，不改项目美术风格。

## 拆镜规则

- **子镜头密度**：同一段落 2-3 个【镜头N】即可；优先「建立空间 → 跟拍主体 → 细节/环境收束」
- **切镜**：少切、慢切；同一机位可多停留；避免炫技甩镜与快速蒙太奇
- **时长**：叙事/观察段 10-15 秒；允许单个子镜头 4-6 秒跟拍
- **description**：写观察者视角——人物自然行为、环境声源、现场质感；避免戏剧化夸张表演描写
- **movement / shot_type**：固定、轻推、肩扛感跟镜为主；慎用大仰大俯与快速摇移
- **atmosphere**：现场光、环境噪声、空气尘埃、纪实色调；少写舞台光效

## video_prompt 规则

在底座 3 秒分段之上追加：

- 运镜克制：固定 / 轻推 / 轻跟；少写急摇、环绕、冲击变焦
- 切镜用「切到」时也保持观察感，重新交代主体但不要频繁换景别轰炸
- 动作写日常可见行为；情绪靠停顿、视线、手部细节外化，不写内心独白
- 可写环境音与现场声（远处车声、空调、人群嘈杂）增强纪实感
