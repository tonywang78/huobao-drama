# 手工新建分镜

## 目标

AI 分镜拆分失败或不可用时，支持在分镜页手工逐条创建空镜头，并可插入到指定位置。

## 交互

| 场景 | 行为 |
|------|------|
| 空列表 | 「开始拆分」+「手工新建」；新建后进入工作台并选中 #01 |
| 有列表 | 列表底部「+ 新建分镜」→ 追加到末尾 |
| 卡片 | 「在此后插入」；仅 #01 额外提供「在此前插入」 |
| 新建结果 | 空白描述、时长默认 10s、无绑定；自动选中后编辑 |

## API

扩展 `POST /storyboards`：

- `after_storyboard_id`：插在该镜之后
- `before_storyboard_id`：插在该镜之前
- 都不传：追加到本集末尾（`max(number)+1`，空集则为 1）
- 二者互斥；定位镜头必须属于 `episode_id`

服务端将 `storyboard_number >= N` 的镜头整体 +1 后插入新行（`N` 为目标序号），并更新本集 `episodes.duration`。
